# 시간표 메이트

친구들의 에브리타임 시간표를 한곳에 모아 보는 모바일용 PWA입니다.
서버 없이 정적 파일만으로 동작하고, 한 번 열면 인터넷 없이도 사용할 수 있어요.

## 기능

- **지금**: 나와 친구가 지금 수업 중인지, 공강인지, 다음 수업은 언제인지 한눈에 보여줘요
- **시간표**: 사람별 주간 시간표, 현재 시각 표시, 과목을 누르면 상세 정보와 같이 듣는 사람이 나와요
- **공강 찾기**: 고른 사람들이 모두 비는 시간을 요일별로 찾아줘요 (시간 범위 조절 가능)
- **설정**: 에브리타임 `.htm` / `.html` 파일로 내 시간표·친구 시간표 추가, 업데이트, 이름 변경, 삭제, JSON 백업과 복원

데이터는 기기의 `localStorage`에만 저장되고 외부로 전송되지 않아요.

## 시간표 파일 만들기

1. PC 브라우저에서 everytime.kr의 시간표 페이지(친구 시간표는 친구 → 시간표)를 열어요
2. `Ctrl + S`로 웹페이지를 저장해요 (HTML만 / 전체 모두 가능)
3. 저장한 파일을 휴대폰으로 옮긴 다음 앱 **설정**에서 선택해요

## 실행 / 배포

PWA(서비스 워커)는 HTTPS나 `localhost`에서만 동작해요.

```bash
python3 -m http.server 8000   # http://localhost:8000
```

GitHub Pages 같은 정적 호스팅에 저장소 루트를 그대로 올리면 돼요. 모든 경로가 상대 경로라서 하위 경로에 올려도 동작해요.
앱 파일을 수정하면 `sw.js`의 `VERSION`을 올려야 설치된 기기에 새 버전이 반영돼요.

## 구조

```
index.html             앱 셸
css/style.css          모바일 우선 스타일 (다크 모드 지원)
js/parser.js           에브리타임 HTML 파서
js/store.js            localStorage 저장소
js/app.js              화면 렌더링과 이벤트 처리
sw.js                  오프라인 캐시용 서비스 워커
manifest.webmanifest   PWA 매니페스트
icons/                 앱 아이콘
```

### 파싱 방식

에브리타임은 과목 블록(`.subject`)을 요일별 `<td>` 안에 `top`/`height`(px)로 절대 배치하고, 기본 배율은 1분당 1px이에요.
`_timetableGridInfo`와 교시 눈금 위치로 배율을 확인한 다음 시작·종료 시각을 계산하고, 5분 단위로 반올림해요.
과목명은 `h3`, 교수는 `em`, 강의실은 `span`에서 가져와요.
